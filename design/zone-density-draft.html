四区密度候选

同一套 DOM、同一套文案，只换 CSS —— 用来判断「四个区占多大」这件事。
高度为 1440px 视口下脚本实测，另在 860 / 520px 断点验过不溢出。

预览稿 · 未落地
A · 现状站点当前实测 —

图标 / 名称 / 英文名 / 描述 2 行 / 药丸贴底。信息一条不少，是四者里最占面积的。

B · 图标与名称同行实测 —

只把「图标独占一行」改成与名称并排，省掉一行约 22px。信息仍是一条不少，视觉上更紧凑，代价是图标与标题同高、图标显得略小。

C · 描述单行省略实测 —

描述限一行（超出打省略号），英文名隐藏，药丸移到右上角。代价：描述会被截断 —— 例如「…四级 / 六级 / 考研 / 考博 / 托福 / GRE」只剩前半句。

D · 单行导航条实测 —

四区变成一条导航栏，图标 + 名称 + 计数，描述默认收起、鼠标悬停浮出（图中第二张演示了悬停态）。最省面积，但描述不再一眼可见，触屏设备上基本用不到。
